# OpenOrg — Astro themes

OpenOrg makes paid, ready-to-use themes for [Astro](https://astro.build) sites.

## Themes

### Nightgrid

Nightgrid is a dark, single-accent Astro theme for a software product site. It
has a home page with an animated hero, plus blog, about, pricing, contact,
documentation, changelog, legal and 404 pages. The site is static: there is no
server code, no form backend, no analytics and no tracking. All text in the
theme is placeholder copy for a fictional product, ready to be replaced with
your own.

- Pages: home, blog, about, pricing, contact, documentation, changelog, legal and 404
- A search dialog (Cmd+K or Ctrl+K), an RSS feed and a sitemap
- Content in Markdown collections for docs, blog posts and changelog entries, with templates to copy
- Four visual presets, with overrides for accent color, background, borders, radius, button shape, glow and font
- One site config file for name, URL, navigation, footer, links and SEO
- A contact form, a newsletter field and a cookie consent banner that you connect to services of your choice
- Self-hosted Inter and Inconsolata fonts (SIL Open Font License)
- A design guide (`DESIGN.md`) and instructions for AI coding assistants (`AGENTS.md`)

Built with Astro 7, Tailwind CSS 4, Lucide icons and Lenis.

### Dimlit

Dimlit is a dark, minimal Astro theme for a mobile app's landing site. Its
home page is built around animated phone screens, and it adds blog,
changelog, help center, contact, legal and 404 pages. The site is static:
there is no server code, no form backend, no analytics and no tracking. All
text in the theme is placeholder copy for a fictional app, ready to be
replaced with your own.

- Pages: home, blog, changelog, help center, contact, privacy, terms and 404
- A download dialog with a QR code, and one store button on phones
- A help center that answers from your own Markdown articles, in the browser
- Content in Markdown collections for blog posts, releases and help articles, with templates to copy
- Brand color, corner radius and button shape set in one theme config file
- One site config file for name, URL, navigation, footer, store links and feature switches
- A contact form, a newsletter field and a cookie consent banner that you connect to services of your choice
- Quiet motion that respects reduced motion and works without JavaScript
- Self-hosted Inter and Inconsolata fonts (SIL Open Font License)
- A design guide (`DESIGN.md`), detailed guides in `docs/` and instructions for AI coding assistants (`AGENTS.md`)

Built with Astro 7, Tailwind CSS 4, Lucide icons and Lenis.
